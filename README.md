# نظام إدارة محلات الصاغة والذهب والمجوهرات الذكي (Gold Jewelry SaaS)

نظام سحابي متكامل ومخصص لتجارة الصاغة والمجوهرات، مدعوم بالذكاء الاصطناعي (Gemini Vision) لإدارة نقاط البيع، فواتير المبيعات، شراء الكسر، ميزان الذهب بالجرام، والخزينة النقدية.

---

## الميزات الرئيسية

1. **شاشة نقاط البيع السريعة (Fast POS):**
   - **وضع بيع الذهب الجديد:** حساب (الوزن الصافي × سعر الجرام) + المصنعية + ضريبة القيمة المضافة والدمغة القانونية.
   - **وضع شراء الكسر والمستعمل:** خصم وزن الفصوص والشوائب آلياً مع توثيق الرقم القومي للعميل لحماية المحل قانونياً.
   - أزرار سريعة للأصناف الشائعة (غوايش 21، خواتم لازوردي 18، سبائك BTC، جنيهات ذهب).

2. **شريط أسعار البورصة الحية (Live Gold Ticker):**
   - عرض لحظي لأسعار البيع والشراء لعيارات 24، 21، 18، 14 والجنيه الذهب.
   - نافذة سريعة لتحديث الأسعار وتطبيقها فورياً على جميع الفواتير والمخزون.

3. **الفحص البصري بالذكاء الاصطناعي (Gemini Vision):**
   - مسح بطاقة الرقم القومي المصرية واستخراج الاسم والرقم القومي والعنوان آلياً خلال ثانيتين.
   - فحص كروت السبائك (مثل BTC ولازوردي) وقراءة الماركة، السيريال، والوزن وتعبئتها في الفاتورة بضغطة زر.
   - فحص وضوح الدمغة وختم مصلحة الدمغة والموازين.

4. **ميزان الذهب والخزينة اليومية (Daily Gold Ledger):**
   - حساب دقيق لميزان الجرامات المعادل لعيار 21 (خرج كذا جرام ودخل كذا جرام كسر).
   - حساب السيولة النقدية في الدرج (المقبوضات - المدفوعات).

5. **الطباعة الحرارية والتواصل:**
   - طباعة فواتير حرارية (Thermal 80mm) بنقرة واحدة (F9 أو زر الطباعة).
   - إرسال تفاصيل الفاتورة والضمان للعميل على واتساب مباشرة.

## كيفية التشغيل السريع:

1. انقر نقراً مزدوجاً على الملف:
   `F:\مشروعات saas\gold\run_gold_system.bat`
2. سيفتح السيرفر والواجهة تلقائياً ويفتح المتصفح على:
   `http://localhost:5174`

---

## النشر السحابي (على نفس خادم المشروع الأول في غيمة):

يمكن نشر هذا المشروع بجوار مشروع السنتر الأول بكل بساطة:
- عبر **Nginx** بتوجيه رابط فرعي (مثلاً: `gold.yourdomain.com`).
- يعمل مشروع السنتر على البورت الخاص به، ومشروع الذهب على بورت مستقل (مثل 8000 و 5174).
- كلا المشروعين معزول تماماً بقاعدة بياناته وإعداداته دون أي تعارض.
